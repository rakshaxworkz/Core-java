1)Explain
i)Public static void main(String args[])
	Public - is access specifier where JVM can easily accesss the main
	static - is non access specifier where the copy or the instance is not created.
	void - is the return type - with no return type
	main - is the name of the method
	(String args[]) - it is a parameter with arguement.

ii)Class and Object
	class - Class is a blueprint or template which has state and behavior, state refers to the variables , behavior refers to the methods.
	Object - Object is a instance or copy of class

iii)JVM,JRE,JDK
	JVM : Which stands for Java Virtual Machine
 	It is a component which provides run time environment to run or execute the bytecode or javacode.

	JRE : Which stands for Java Run time Environment
	It is the combination of JVM and set of libraries
	It is the software package that provides everything the user needs to execute the javacode.

	JDK : Which stands for Java Development Kit
	It is the component that is fully featured tools to compile and execute the java code.
	It is the combination of JRE + development tools(such as compiler, debugger, Javadoc).

8)Can we use instance variable inside the static method?

	No, Instance variable should be declared outside the method but inside the class, Because instance variable which can create copies , but static 	keyword is not allowed to create instances so we cannot use instance variable inside the static method.

9)Explain Polymorphism with example?

	Polymorphism refers to the  object behaving differently at given instance of time, It is achieved through the annotation @Override, which means the 	child is not happy with the parent method structure it overrides the same method but implement in its own way.
	It can be done by 

	Parent ref = new Child();

	Example for polymorphism?
	Class Engineer{
		public void solveProblems(){
			System.out.println("Engineers solve the complex problems");
	}
	@Override
	Class CsEngineer extends Engineer{
		public void solveProblems(){
			System.out.println("CS Engineers solve the complex problems");
	}
	}
	}

	Class EngineerRunner{
		public static void main(String args[]){
			Engineer engineer = new CsEngineer();
			CsEngineer.solveProblems();
	}
	}
